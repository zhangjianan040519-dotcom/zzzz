## 一、任务背景

### 研究问题

酱油的咸味强度是决定其风味品质与消费者接受度的关键指标，但传统上只能依靠感官评价小组打分获得，成本高、周期长、主观性强。如果能用仪器测得的理化与风味物质含量**定量预测**咸味评分，就可以大幅压缩感官评价的工作量。

### 数据是怎么来的

本研究以 56 个酱油样品为对象，用仪器测定其风味物质含量，并配套做了感官评价打分。建模前经历了两步预处理：

1. **剔除异常样本**。在数据清洗阶段，S06、S08、S15、S22、S26、S29、S31、S49 共 8 个样品被判定为异常样本并剔除，保留 **48 个样品**。
2. **扩充样本量**。为提升数据多样性、同时严格保留原有的组间变量结构，每个样品做了 **6 次生物学重复**（`n_copies = 6`）。

最终进入建模的数据集为 **288 个观测（48 样品 × 6 次重复）**。

### 指标体系的构成

每个样品测定了 **40 个风味活性指标**，分为五大类：

| 类别 | 数量 | 具体指标 |
| --- | --- | --- |
| 有机酸（OAs） | 10 | 丙酮酸、酒石酸、L-苹果酸、焦谷氨酸、乳酸、富马酸、琥珀酸、草酸、柠檬酸、维生素C |
| 核苷酸 | 5 | 5'-AMP、5'-GMP、5'-CMP、5'-UMP、5'-IMP |
| 游离氨基酸（FAAs） | 18 | Ala、Arg、Asp、Glu、Gly、His、Ile、Leu、Lys、Met、Phe、Pro、Ser、Thr、Trp、Tyr、Val、Cys |
| 无机盐离子 | 5 | Na⁺、K⁺、Ca²⁺、Mg²⁺、Cl⁻ |
| 理化指标 | 2 | NSSS（可溶性无盐固形物）、NaCl |

**预测目标（因变量）**：咸味评分（`咸味评分`）——由感官评价小组给出。

### 为什么要做降维

对全部 40 个参数做 Pearson 相关性分析后发现，**变量之间存在严重的多重共线性**（例如 Na⁺ 与 NaCl、NSSS 与其他固形物指标天然高度相关）。多重共线性会让回归系数估计不稳定、方差膨胀，直接把 40 个指标全部丢进预测模型会导致**过拟合**。

因此在正式建模之前，必须先用 **Lasso 回归（L1 正则化）做一步降维**，把对咸味贡献可忽略的指标系数压缩到 0，筛出一组"非冗余的核心指标"，再交给后续的非线性模型（GB、RF、SVR 等）使用。

**你的任务，就是独立复现这一步降维分析。**

## 二、数据说明

数据位于 `data/` 目录，两个文件列结构完全相同（**42 列**：`ID` + `咸味评分` + 40 个指标），行数均为 288。

| 文件 | 说明 |
| --- | --- |
| `data/soy_sauce_flavor_raw.csv` | 清洗后的**原始测量值**（未标准化） |
| `data/soy_sauce_flavor_standardized.csv` | 同一批数据的 **Z-score 标准化**结果，已可直接输入 Lasso |

- 第一列 `ID` 为观测编号（1–288），仅作标识，**不参与建模**。
- 第二列 `咸味评分` 为回归目标 y，**不参与建模**。
- 其余 40 列为自变量 X。

> **关于标准化**：Lasso 的 L1 惩罚项对各变量是对称的，如果各指标量纲不同（例如 NaCl 是 g/100 mL 量级、5'-GMP 可能是 mg/100 mL 量级），惩罚会**不公平地偏向小量纲变量**，导致结果不可信。因此 Lasso 必须在标准化数据上做。
> 为方便起见，`soy_sauce_flavor_standardized.csv` 已经做好 Z-score。如果你想完整走一遍流程，也可以从 `soy_sauce_flavor_raw.csv` 出发，自己算 Z-score 后与标准化文件比对验证。

**读取示例**（注意列名含中文，请用 UTF-8 读取）：

```python
import pandas as pd

df = pd.read_csv('data/soy_sauce_flavor_standardized.csv', encoding='utf-8')

X = df.drop(columns=['ID', '咸味评分'])   # (288, 40)
y = df['咸味评分']                        # (288,)

print(X.shape, y.shape)   # (288, 40) (288,)
```

## 三、任务要求

用 **Lasso 回归 + 10 折交叉验证**完成降维，并绘制以下**三张图**。

### 图 1：Lasso 系数路径图（Coefficient Profiles）

- **横轴**：`log(λ)`
- **纵轴**：各指标的回归系数
- **内容**：40 个指标各画一条曲线，展示随惩罚强度 λ 增大，各指标系数如何被逐步压缩至 0。
- **必须标注**两条竖直参考线：
  - **λmin**（最小 MSE 对应的 λ）——黑色虚线
  - **λ1se**（一倍标准误准则对应的 λ，即最简约模型）——红色点线
- 图例中需写出 `log(λmin)` 与 `log(λ1se)` 的**具体数值**。

### 图 2：10 折交叉验证误差曲线（Cross-Validation Error Curve）

- **横轴**：`log(λ)`
- **纵轴**：交叉验证 **均方误差（MSE）**
- **内容**：每个 λ 下 10 折交叉验证的 MSE **均值**，并用**误差棒**表示其标准误（`std / sqrt(10)`）。
- 同样标出 λmin 与 λ1se 两条竖线，并在图中以文本框给出二者的具体数值。

> 注：纵轴用 **MSE**（Mean Squared Error），不是 RMSE。

### 图 3：指标系数条形图（Coefficient Bar Plot）

- **形式**：水平条形图
- **纵轴**：指标名称——**只画 Lasso 筛出的非零系数指标**（系数被压缩为 0 的指标不出现）
- **横轴**：回归系数
- **排序**：按系数大小排序（便于阅读）
- **标注**：每根柱子末端写出系数的具体数值
